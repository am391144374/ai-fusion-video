# 分镜直接生成视频开发计划

## 目标

在分镜列表中提供不经过 Agent 的视频生成入口。单条和批量任务均复用既有视频生成接口与任务落库；批量由前端固定按并发 1 串行执行，当前任务成功后才提交下一条，失败后暂停后续任务。

## 实现范围

1. 扩展现有分镜视频生成弹窗，保留 Agent 生成入口并增加直接生成模式。
2. 直接生成时统一选择视频模型；每条分镜使用自身的视频提示词和时长。
3. 每条分镜可自主选择文生视频、首帧、首尾帧或资产图作为参考图来源。
4. 复用 `/api/generation/video/submit`、任务查询与 `storyboardApi.updateItem`，使任务创建和分镜视频回填与既有生成链路一致。
5. 批量提交后展示进度弹窗，显示分镜 ID、提示词、时长、参考图、状态和失败原因。
6. 当前任务失败后暂停队列，已成功项和失败信息保留，未提交项显示已暂停。
7. 支持手动停止后续队列：当前正在生成的视频任务继续执行并正常回填，未提交项标记为已停止且不再调用生成接口。

## 不在范围内

- 不新增后端批量生成接口。
- 不修改 Agent 视频生成逻辑。
- 不新增后台持久化队列和断线恢复能力。

## 验证

- 前端类型检查与 lint。
- 校验提交参数、串行成功推进、失败暂停、缺少提示词拦截和视频 URL 回填。
- 验证原 Agent 生成入口仍可使用。
