# 分镜自定义视频上传设计

## 目标

在分镜列表的表格视图和卡片视图中支持上传自定义 MP4 视频。上传完成后，将视频地址保存到分镜条目的 `generatedVideoUrl`，与 AI 视频生成完成后的保存、预览和分集视频合成逻辑保持一致。

## 已确认范围

- 仅接受 MP4 文件。
- 同时支持表格视图和卡片视图。
- 自定义视频覆盖该镜头现有的 `generatedVideoUrl`；不修改 `videoPrompt`。
- 不新增后端字段、接口或数据库迁移。

## 实现设计

1. 两种分镜视图均在镜头的既有操作区增加“上传视频”入口，并在上传期间禁止重复提交。
2. 前端在打开文件选择器后校验 MIME 类型或文件名后缀；非 MP4 文件不上传并提示用户。
3. 使用现有通用存储上传接口，将文件保存到 `storyboard-videos` 目录。
4. 上传成功后调用既有 `storyboardApi.updateItem`，只提交 `id` 与 `generatedVideoUrl`。
5. 使用更新接口返回的完整分镜条目替换页面局部状态，确保视频缩略图、预览和分集视频合成立即读取同一字段。

## 错误处理

- 非 MP4：在选择后立即提示“仅支持 MP4 视频文件”。
- 上传失败：保留原有视频，不调用分镜更新接口，并提示上传失败。
- 保存失败：不更新页面局部状态，提示保存失败；已上传的文件由既有存储策略管理。

## 验证范围

- MP4 上传后写入 `generatedVideoUrl` 并可立即预览。
- 非 MP4 文件被拒绝，且不发起上传。
- 上传或保存失败时保留原分镜视频。
- 原有 AI 视频生成后的视频展示和分集视频合成仍读取 `generatedVideoUrl`。
