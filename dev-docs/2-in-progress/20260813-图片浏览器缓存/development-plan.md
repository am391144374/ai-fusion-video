# 图片浏览器缓存开发方案

## 目标

为后端本地媒体路径 `/media/**` 返回的图片配置浏览器长期缓存，避免页面刷新后重复下载未变更的图片；图片更新后因地址变化，浏览器自动请求新地址并使用新缓存。

## 方案

在 `WebMvcConfig` 的 `/media/**` 静态资源映射上配置一个月缓存，并标记为不可变资源。

- 同一图片地址在缓存有效期内直接从浏览器本地读取，不请求服务器。
- 图片更新后使用新的地址。新地址是新的缓存键，浏览器自动下载最新图片。
- 不修改前端各处图片组件，也不追加随机参数，避免重复逻辑和无效请求。
- 不改变 `/api/art-styles/**` 以及其他接口的缓存行为。

## 验证

1. 为 `WebMvcConfig` 增加测试，断言 `/media/**` 资源处理器包含一个月缓存配置。
2. 执行相关 Maven 测试，确认现有静态资源映射未受影响。
