# 视频生成 Skill 加载校验修复开发计划

## 目标

修复生成视频时 AgentScope 调用 `load_skill_through_path`，但工具参数 `skill_id` 的枚举为空而导致请求失败的问题。

## 根因

- 用户 Skill 存在按用户隔离的远程工作区中。
- Harness Agent 在无用户上下文的共享构建阶段注册工作区 Skill 加载器，无法枚举具体用户的 Skill，因此产生空的 `skill_id` 枚举。
- 当前业务流程已经将用户主动选择的 Skill 正文完整注入系统提示词，再次动态加载属于重复路径。

## 实施范围

1. 区分“配置了仓库”和“仓库内实际存在 Skill”。
2. 禁用共享 Agent 的用户工作区动态 Skill 加载通道。
3. 仅在仓库中实际存在 Skill 时挂载静态仓库并启用 Skill。
4. 增加空仓库与远程工作区组合的回归测试。
