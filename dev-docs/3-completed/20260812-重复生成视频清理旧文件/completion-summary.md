# 重复生成视频清理旧文件完成总结

## 最终行为

- 分镜已有视频且新视频 URL 不同时，先成功更新数据库，再删除旧视频原文件。
- 数据库更新失败时不删除旧文件，保留原视频可用性。
- 新旧 URL 相同、文件不存在或 URL 不属于当前存储时不执行删除。
- 删除旧文件失败不会撤销已成功生成的新视频，会记录明确错误日志。

## 存储支持

- 本地存储：仅接受 `/media/...` 相对 URL，并校验规范化路径仍位于媒体根目录内。
- S3 兼容存储：校验域名、访问路径和配置前缀后，通过 bucket 与 object key 删除。

## 回归覆盖

- 数据库更新后再删除旧文件。
- 数据库更新失败、URL 相同不删除。
- 本地路径越界与外部绝对 URL 防误删。
- S3 当前域名对象删除与外部域名拒绝。
