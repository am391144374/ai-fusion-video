# 完成总结

## 最终范围

修复 ComfyUI `SaveVideo` 输出的 MP4 文件被放入 `images` 数组时，后端将其误判为图片并过滤的问题。未修改前端、数据库、输出绑定格式和 `/view` 下载接口。

## 关键实现

- 输出媒体类型优先根据 `format` 判断。
- 缺少 `format` 时根据 `filename` 扩展名判断。
- 只有文件自身信息不足时，才根据 `images`、`videos`、`audio` 等输出字段名兜底判断。
- 增加真实返回结构回归测试：节点 `92` 的 `images` 数组中包含 `.mp4` 文件时，能够匹配 `video` 输出绑定。
