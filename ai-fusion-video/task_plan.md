## 已做决策（Decisions Made）

| 决策 | 理由 |
|------|------|
| 以 H3 原始 Skill 及两个参考格式为验收依据 | 用户明确指定该 Skill 作为提示词生成规则 |
| 在分镜视频执行 Agent 的提示词中实现模式选择 | 该 Agent 持有首尾帧、参考图、时长和模型能力，且是 `videoPrompt` 的唯一生成点 |

## 遇到的错误（Errors Encountered）

| 错误 | 尝试次数 | 解决方式 |
|------|----------|----------|
| 初次查找现有视频提示词测试未命中并返回退出码 1 | 1 | 改为按 Agent 注册和提示词资源定位测试入口；不影响代码链路确认 |
| Maven 使用 Java 8，无法加载 Spring Boot 3.5.14 构建插件 | 1 | 查找本机 Java 17+ 并切换 `JAVA_HOME` 后重试定向测试 |
| JDK 17 可启动 Maven，但项目以 release 21 编译 | 1 | 查找本机 JDK 21；若不存在，明确记录环境阻塞 |
| JDK 26 下的 Maven 定向测试超过单次命令 120 秒时限 | 1 | 检查已有编译产物；必要时以隐藏后台进程执行并轮询日志 |
| 后台 Maven 测试将标准输出和错误输出重定向到同一文件 | 1 | 改为分别重定向两个日志文件后启动 |
| PowerShell 将 Maven `-Dtest` 参数中的逗号解析为参数分隔符 | 1 | 为该参数加引号后重新执行 |
